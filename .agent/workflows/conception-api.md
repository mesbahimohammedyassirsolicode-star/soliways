# Workflow: Conception API

## Prerequisite
Validated brief. Content architecture and manifest when they exist (they tell which data each component needs).

## Steps
1. **Skill**: `architecte-api`. ERD in `docs/data-model.md`.
2. Write `contracts/openapi.yaml`: endpoints, schemas, auth, errors, pagination, examples.
3. Traceability table: component or screen -> endpoint.

## Checkpoint
Present the ERD summary and the endpoint list. Wait for GO. After GO the contract is frozen.
