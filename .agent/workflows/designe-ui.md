# Workflow: Designe UI

Runs three sub-workflows in order. Each has its own checkpoint.

1. `/charte-graphique` -> GO
2. `/conception-ui` -> GO
3. `/creation-ui` -> GO (the user validates components visually)

If mobile is in scope, the charte includes Compose tokens and the manifest includes mobile components. The mobile component catalog itself is built in `/develope-mobile`, reusing the same tokens.
