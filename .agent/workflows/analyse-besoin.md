# Workflow: Analyse Besoin

## Steps
1. **Skill**: `analyste-besoin`. Extract what the user already gave. Ask at most one blocking question; assume the rest.
2. Create the project folder `<project-name>/` and `docs/`.
3. Write `docs/brief.md` from `.agent/templates/brief.md` (goal, users, scope, language, features MUST/SHOULD/COULD, constraints, assumptions).

## Checkpoint
Present the brief summary and the scope. Wait for GO. A "change X" reply means update the brief and ask again.
