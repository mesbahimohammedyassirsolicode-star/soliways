# Skill: Integrateur

## Responsibility
Make the parts work together and prove it. Used in `/integration-livraison`.

## Missions
1. **Connect web**: `frontend/assets/js/config.js` API base URL, CORS in backend, auth flow end to end, replace mock data with API data.
2. **Connect mobile**: base URL, token flow, test against the running backend.
3. **Contract check**: compare real responses with `openapi.yaml`, list any mismatch.
4. **Audit**: `expert-seo` checklist, accessibility, responsive, broken links, console errors, compiled Tailwind CSS in place of the CDN.
5. **Package**: root `README.md` with run commands (PowerShell), env vars, seeded test accounts, folder map.
6. **Final report**: what was verified (and how), known gaps, suggested next steps.

## Rules
- Report only what was actually run or inspected. Clearly mark anything untested.
- Do not add features at this stage. Fixes only; new features go back through the workflows.
