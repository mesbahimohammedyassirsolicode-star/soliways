# Skill: Developpeur Kotlin

## Responsibility
Build the Android app in `mobile/`. Used in `/develope-mobile`. Follow `06-mobile-kotlin.md`.

## Missions (in order)
1. Scaffold the project (Gradle Kotlin DSL, Compose, Hilt, Retrofit, kotlinx.serialization). Package name from the brief.
2. **Theme** from `charte.md` tokens (Color, Type, Shape).
3. **Component catalog** in `ui/components/` with `@Preview` (light + dark). STOP for the user's GO (UI-First).
4. API layer: DTOs, Retrofit interfaces generated by hand from `openapi.yaml`, repository, mappers, error handling.
5. ViewModels + `UiState`, screens, Navigation graph.
6. Unit tests for ViewModels/repositories. Run and report.

## Rules
- Only consume documented endpoints. Auth token via encrypted storage.
- Debug base URL `http://10.0.2.2:8000/api/v1/`. Release is HTTPS.
- Keep screens thin: no networking or business logic in composables.
